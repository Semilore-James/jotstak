The reference page says what the parameters do. This page says which look to reach for, with a worked example of each and the reasoning behind the choice.

## What this page has to cover

- `dir=down` as an outline — quiet enough to sit inside prose
- `dir=right` as aligned columns — a breakdown that reads level by level
- `dir=down nodes=boxed` as a chart — an infographic that carries weight
- `dir=split` as a bilateral map, and `>` / `<` to pin a side
- How sibling order affects the shape, and what it does not affect
- When a tree is the wrong answer
