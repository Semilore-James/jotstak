A directory of diagrams by INTENT, not by name. Someone arrives knowing they have a hierarchy, a sequence or a trade-off — not knowing that the answer is called `@tree`.

## What this page has to cover

- A hierarchy that breaks down → `@tree`
- A sequence over time → `@timeline` (not built yet)
- Two axes of trade-off → `@matrix` (not built yet)
- A path a person takes → `@journey` (not built yet)
- A system of five parts → `@star_model` (not built yet)
- When the answer is a table, and when it is prose
