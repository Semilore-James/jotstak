Engineers already write in Markdown and already review in pull requests. The argument is that the diagram should live there too, instead of in a canvas nobody updates.

## What this page has to cover

- Diagrams that diff, line by line
- Review in the same place as the code
- Keeping an architecture drawing honest by keeping it in the repo
- What to do when a diagram genuinely needs a canvas
