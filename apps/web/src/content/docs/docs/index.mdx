Jotstak is a way to write the documents product people write — specs, decisions,
plans — as one plain text file, with the tables and diagrams inside it, and read
it as pages in a notebook. If you can write Markdown, you can already write it.

## Start here

- **[Quick start](/docs/start/)** — from a Markdown file you already have to your
  first block, in a few minutes.
- **[Playground](/playground)** — try it in your browser. Nothing to install.
