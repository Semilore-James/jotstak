Every block is written the same way, and any block can go inside any other. There is no list of allowed combinations to learn.

## What this page covers

- `@name(setting=value)` then indented content
- Putting a block inside another one
- When to use `@panel` instead of a named card like `@risk`
- A short example that nests three deep
