Every block is written the same way. Most blocks can go inside a `@panel`, a `@callout` or one of the other cards; a few hold only text, and a few belong to the page itself. The full list is in [What goes inside what](/docs/functions/#what-goes-inside-what).

## What this page covers

- `@name(setting=value)` then indented content
- Putting a block inside another one, and which blocks can hold one
- When to use `@panel` instead of a named card like `@risk`
- A short example that nests three deep
