The feature the whole tool exists for: write the structure, get the picture, and it lives in the same file as the argument for it.

## What this page covers

- A tree is lines with indentation under `@tree`
- Four looks: an outline, columns, a chart, a balanced map
- Changing the look is one setting, not a redraw
- A diagram that does not fit is shrunk or given its own page — never cut off
- What is coming: matrix, timeline, journey, star model
