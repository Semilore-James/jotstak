A margin note is the aside you would scribble in a real notebook. Write `@note` and it appears beside the paragraph above it.

## What this page covers

- `@note your text` on its own line, or `@note` with the text indented under it
- A note sits beside the paragraph it follows
- Text makes room for a note; without one it uses the full width
- Two notes close together are moved apart for you
