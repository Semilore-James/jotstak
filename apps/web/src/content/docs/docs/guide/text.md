Kill the assumption that a code-first document format means giving up ordinary writing. Bold, italics, links and code work everywhere text works — including inside diagram labels.

## What this page has to cover

- Everything Markdown does, unchanged
- `==highlight==` and where it is capped so it cannot stretch a row
- Inline marks inside node labels, card fields and table cells
- Inline marks in headings
- What is deliberately not supported, and why
