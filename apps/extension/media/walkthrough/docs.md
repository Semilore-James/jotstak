# The docs

At [jotstak.pages.dev/docs](https://jotstak.pages.dev/docs/):

- **Get started**: from an empty file to a first document.
- **Writing**: blocks and indentation, margin notes, diagrams, pages and printing.
- **Examples**: whole documents to copy from.
- **Reference**: every block and every setting.

The playground at [jotstak.pages.dev/playground](https://jotstak.pages.dev/playground) needs no install, and its **Start here** sample is the welcome document.
